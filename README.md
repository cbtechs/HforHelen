# HforHelen Website

A modern, professional website to replace the existing Linktree page for Helen.

## Project Overview

This project transforms the existing Linktree (https://linktr.ee/HforHelen) into a full-fledged custom website with enhanced design, UX, and functionality.

## Features

- **Modern, Responsive Design**: Mobile-first, fast-loading, SEO-optimized
- **Complete Content Migration**: All existing links, media, and content preserved
- **Enhanced Sections**:
  - Homepage with hero section and quick-access buttons
  - Expanded About/Bio page with visuals
  - Services/Offerings with clear CTAs
  - Portfolio/Gallery showcase
  - Contact/Booking with integrated calendar
  - Social media integration

## Tech Stack

- **Framework**: Next.js with TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: TBD
- **Analytics**: Integrated tracking
- **Performance**: Optimized for speed and SEO

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Branches

- `main`: Production-ready code
- `dev`: Development branch for new features
